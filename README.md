# Statisztika gyakorló

Véletlenszerűen generált gyakorlófeladatok a Statistics (University of Pannonia) zh anyagához: arányok, viszonyszámok, gyakorisági sorok, középértékek, szóródás, mintavétel, hipotézisvizsgálat, ANOVA.

Megnyitás: https://zsalrick.github.io/statistics/

Fejlesztés: `node check.js` minden feladatgenerátort lefuttat és ellenőrzi, hogy 4 különböző válasz jön-e ki, pontosan egy helyessel.
